# International Commodity Trading & Shipment Profitability

Power BI Executive Dashboard | FY2024–FY2026

## 📊 Project Overview

This project is an end-to-end Power BI portfolio project focused on International Commodity Trading and Shipment Profitability.

The project follows the business process from supplier and purchase through contract, shipment, buyer, revenue and profitability.

The objective was to understand the business process, prepare and validate the data, build a data model and create an executive dashboard to generate meaningful business insights.

## 📦 Synthetic International Commodity Trading Dataset

This project uses a **Synthetic International Commodity Trading Dataset** created specifically for portfolio demonstration and data analytics practice.

The dataset simulates international commodity trading activities including:

- Suppliers and purchases
- Contracts
- Shipments
- Buyers and customers
- Commodities
- Revenue
- Purchase costs
- Profitability
- Trade destinations

All data and figures are synthetic and created for learning and portfolio purposes. They do not represent real business transactions or confidential information from any company.

## 🎯 Business Objectives

- Analyse revenue and profitability across commodities.
- Identify profitable and loss-making transactions.
- Analyse customers and buyer concentration.
- Understand trade destinations and shipment patterns.
- Monitor financial and operational performance.
- Create an interactive executive dashboard for business analysis.

## 📈 Key KPIs

The dashboard provides analysis of:

- Revenue
- Purchase Cost
- Gross Profit
- Profit Margin
- Shipment Value
- Number of Transactions
- Loss-Making Transactions
- Customer and Market Performance

## 🔄 Data & Analytics Workflow

Supplier → Purchase → Contract → Shipment → Buyer → Revenue → Profit

The project workflow included:

1. Synthetic dataset creation
2. Data cleaning and validation
3. Data transformation using Power Query
4. Data modelling in Power BI
5. DAX measure development
6. Dashboard design
7. Business analysis and insight generation
